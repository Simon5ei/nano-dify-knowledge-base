4时序视图 · 召回测试

POST /api/datasets/{id}/hit-testing —— 按 retrieval_mode 路由，Rerank 可选叠加

用户 → 前端
输入 query / TopK / 阈值 / Rerank 开关
前端 → 路由
POST /hit-testing
路由 → SQLite
读 datasets.retrieval_mode，决定召回路径
ALT · vector 向量召回
  • embed_query(query)：settings_store 取生效配置（界面 > 环境变量 > 默认）
  • 取启用分段的 embedding 向量 → 余弦相似度排序（0~1）
ALT · bm25 关键词召回
  • tokenize(query)（jieba 分词）
  • 查 segment_terms 倒排，聚合 TF / DF / N / avgdl → BM25Okapi 打分
  • 归一化（最高分 = 1），与向量分共用阈值语义
OPT · 勾选 Rerank（两阶段检索）
  • 粗排取 3×TopK 候选 → rerank(query, candidates)
  • 远程 /rerank 或本地关键词兜底 → 精排 TopK，返回双分数
路由 → SQLite
命中分段 hit_count + 1
路由 → 前端
records：双分数 + search_label + 来源文档
前端 → 用户
命中卡片（得分 / 内容 / 来源）

7设计决策

图之外的约定与已知边界

召回模式双轨
vector（语义，花 token）与 bm25（精确词，零 token）在知识库级别二选一；索引流水线在分段后分流，共用分段/文档/召回测试/Rerank 框架
配置三级优先级
界面设置（DB）> 环境变量 > 内置默认；密钥脱敏展示、永不回传明文
DB 锁纪律
所有网络调用（embedding / rerank）在 SQLite 锁外执行——实测踩过锁重入死锁后定下的规矩
已知边界
BM25 不做语义泛化（同义改写查不到）；hybrid 融合召回留二期，search_label / 双分结构已预留位置
